## Classification

| 能量来源       | 每克热量         | 主要作用               | 消化后的形式   | 优质食物来源              | 是否主要供能 |
| ---------- | ------------ | ------------------ | -------- | ------------------- | ------ |
| 🥣 碳水化合物   | **4 kcal/g** | 快速供能、维持血糖、大脑主要能源   | 葡萄糖      | 米饭、燕麦、红薯、玉米、全麦面包、水果 | ⭐⭐⭐⭐⭐  |
| 🥑 脂肪      | **9 kcal/g** | 长时间供能、储能、保护器官、激素合成 | 脂肪酸 + 甘油 | 牛油果、坚果、橄榄油、深海鱼、鸡蛋   | ⭐⭐⭐⭐   |
| 🍗 蛋白质     | **4 kcal/g** | 肌肉修复、生长、免疫、酶和激素合成  | 氨基酸      | 鸡胸肉、牛肉、鱼、鸡蛋、牛奶、豆制品  | ⭐      |
| 🍺 酒精（非必需） | **7 kcal/g** | 可提供热量，无营养价值        | 乙醇代谢产物   | 啤酒、白酒、红酒            | ⭐⭐     |

### 三大营养素对比

| 项目      | 🥣 碳水    | 🥑 脂肪          | 🍗 蛋白质   |
| ------- | -------- | -------------- | -------- |
| 热量      | 4 kcal/g | 9 kcal/g       | 4 kcal/g |
| 消化速度    | 快        | 慢              | 中等       |
| 能量供应速度  | ⭐⭐⭐⭐⭐    | ⭐⭐             | ⭐        |
| 持续供能能力  | ⭐⭐       | ⭐⭐⭐⭐⭐          | ⭐        |
| 是否储存在体内 | 少量（糖原）   | 大量（脂肪）         | 几乎不储存    |
| 大脑是否依赖  | ✅ 是      | ❌ 否（长期低碳可利用酮体） | ❌ 否      |
| 是否运动首选  | ✅ 是      | 长时间运动          | 饥饿时才大量供能 |
| 主要作用    | 提供能量     | 储能、维持激素        | 修复身体     |

### 身体中的能量储备

|能量储备|储存位置|储存量（约）|可提供热量|
|---|---|---|---|
|血糖|血液|约5 g|约20 kcal|
|肝糖原|肝脏|80~120 g|320~480 kcal|
|肌糖原|骨骼肌|300~500 g|1200~2000 kcal|
|脂肪|脂肪组织|因人而异（可达数千至数万克）|数万至十余万 kcal|
|蛋白质|肌肉等组织|不作为正常储能|紧急情况下供能|

### Recommendations for fat loss period

| 营养素    | 建议摄入                     | 推荐来源           | 作用          |
| ------ | ------------------------ | -------------- | ----------- |
| 🍗 蛋白质 | **120–150 g/天**          | 鸡胸肉、鱼、蛋、牛奶、豆制品 | 保留肌肉、促进恢复   |
| 🥣 碳水  | **180–250 g/天**（根据训练量调整） | 燕麦、糙米、红薯、全麦面   | 提供训练能量、补充糖原 |
| 🥑 脂肪  | **50–70 g/天**            | 坚果、橄榄油、牛油果、深海鱼 | 激素合成、维持健康   |
| 💧 水   | **2.5–3.5 L/天**          | 白开水、无糖茶        | 维持代谢、促进恢复   |
