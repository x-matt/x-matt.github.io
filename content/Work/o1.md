## Feature

### EIS #eis

- 关键字: `MISV2|MISV3|MISV4|MISHisAdapter`
- 关键property

  | Usage         | Property                                                |
  | ------------- | ------------------------------------------------------- |
  | mis opmode    | `adb shell setprop vendor.eis.operation 65793`   |
  | mis algo type | `adb shell setprop vendor.mis.type 19`           |
  | dis dump      | `adb shell setprop persist.vendor.camera.disAlgoDump 1` |

- 关键的overridesetting

  | Name                 | Desc                          |
  | -------------------- | ----------------------------- |
  | MISv2GyroDumpEnabled | dump gyro/acc/hall/frame info |
  | MISv3DisableDIS      | enable dis                    |
  | MISMiIFOVCEnabled    | enable fovc                   |
